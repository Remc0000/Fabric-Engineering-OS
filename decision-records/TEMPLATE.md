# Fabric Decision Record Template

This template is governed by the root [Fabric Engineering OS Constitution](../CONSTITUTION.md).

Use this template only for Microsoft Fabric decisions. Validate all Microsoft product behavior, limits, features, and support claims against current Microsoft Learn guidance before treating them as decision evidence.

## Status

Proposed | Approved | Superseded | Rejected

## Context

Describe the Fabric workload, owners, environment, constraints, assumptions, and linked issue or pull request.

## Decision Drivers

List the architecture, security, data, cost, topology, operational, and governance drivers that make this decision material.

## Options Considered

Summarize each Fabric-only option, including relevant Microsoft Learn validation links, trade-offs, and rejected assumptions.

## Decision

State the selected Fabric option, the scope of the decision, and what is explicitly out of scope.

## Consequences

Document expected benefits, risks, operational obligations, cost implications, reversibility, and follow-up work.

## Validation

Record the evidence used to validate the decision, including Microsoft Learn links for product claims and any tests, prototypes, or review findings.

## Human Approver

Name the accountable human approver, approval date, and approval evidence link. Agent consensus or successful automation is not approval.
