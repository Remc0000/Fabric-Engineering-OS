# Glossary

This glossary is governed by the [Fabric Engineering OS Constitution](../CONSTITUTION.md).

These short definitions aid navigation. Canonical rules remain in the linked policy documents.

| Term | Meaning |
| --- | --- |
| Fabric Engineering OS | This GitHub-first, governed operating system for AI-assisted Microsoft Fabric engineering. See the root [README](../README.md). |
| Microsoft Fabric | The only supported data platform for this OS. Product behavior is validated against Microsoft Learn. |
| GitHub Copilot | The approved agent runtime. It may assist within the boundaries of the [Constitution](../CONSTITUTION.md). |
| GitHub MCP | The repository interface used by the agent runtime. |
| Microsoft Learn | The authoritative source for Microsoft product behavior and limitations. |
| Skills for Fabric | The preferred source of Fabric expertise. |
| Fabric Accelerator | The primary architecture reference. |
| FMD Framework | The primary implementation reference. |
| ELT Framework | A secondary implementation reference used only when justified. |
| Fabric Toolbox | An optional discovery source, not an authoritative or managed dependency. |
| Upstream source | An external source used read-only; this OS never automatically modifies or synchronizes it. |
| Agent | AI assistance that may propose and implement bounded work but cannot satisfy a human approval role. |
| Human gate | A recorded decision by an accountable person for architecture, security, data, merge, release, or production. |
| DEV / TEST | Non-production environments usable only through approved, auditable workflows and human authorization. |
| PROD | Production; agents never deploy to it. Humans approve and perform production actions. |
| Evidence | Reviewable records linking intent, decisions, implementation, validation, and operational impact. |
| Idea | An uncommitted possibility in the [Ideas Backlog](../community/IDEAS-BACKLOG.md). |
| Roadmap item | Accepted direction, not a guaranteed date or release. See the [Community Roadmap](../community/ROADMAP.md). |

For practical application, see [Getting Started](Getting-Started.md) and [Operating Model](Operating-Model.md).
