Community participation is governed by the [Fabric Engineering OS Constitution](../CONSTITUTION.md).

This directory contains the concise, source-controlled rules for contributing to and maintaining Fabric Engineering OS.

## Community boundaries

- Microsoft Fabric is the only supported data platform.
- GitHub Copilot is the agent runtime; GitHub MCP is the repository interface.
- Microsoft Learn is authoritative for product behavior.
- Skills for Fabric is preferred expertise, Fabric Accelerator is the primary architecture reference, and FMD is the primary implementation reference.
- ELT is secondary and Fabric Toolbox is optional discovery.
- Upstream sources are read-only and are never automatically modified.
- Ideas are not commitments. Roadmap placement expresses accepted direction, not a guaranteed date.
- Humans approve pull requests, perform merges, authorize releases, and own every production action.

Use the [source-controlled wiki](../wiki/Home.md) for adopter navigation and the root [Governance model](../GOVERNANCE.md) for canonical decision rights.
