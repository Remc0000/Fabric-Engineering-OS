# Semantic Model Charter

This bundle is governed by the [Fabric Engineering OS Constitution](../../CONSTITUTION.md).

## Mission

Create or evolve a governed Fabric [semantic model](../../capabilities/semantic-model.md) that gives named consumers consistent, performant, secure business meaning. Follow the [semantic-model golden path](../../golden-paths/semantic-model.md).

## Owns

- Consumer questions, model scope, grain, dimensions, facts, relationships, measures, hierarchies, formatting, and descriptions.
- Storage/connectivity decision, refresh behavior, incremental strategy, role security, endorsement readiness, performance, and compatibility.
- DEV/TEST model implementation, automated metadata/query tests, consumer acceptance, evidence, and handoff.

## Requires

A governed gold source, domain-approved definitions, accountable model owner, consumer representative, security classifications, refresh/query SLOs, and capacity/environment constraints.

## Boundaries

The bundle does not redefine domain metrics without approval, compensate for poor source quality invisibly, expose restricted detail, approve endorsement, merge, or deploy PROD. It never modifies Fabric Engineering OS or upstream repositories.

## Exit

Exit with a versioned model contract, documented metric definitions, tested security and performance, refresh/rollback runbook, consumer acceptance in TEST, and human approval requests for endorsement and production.
