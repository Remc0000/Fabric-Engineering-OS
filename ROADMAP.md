# Roadmap

The roadmap is subordinate to the [Fabric Engineering OS Constitution](CONSTITUTION.md). It expresses intent, not a delivery commitment.

## v0.9.0-preview — Foundational OS

- Complete agent roles and scenario bundles.
- Publish the Fabric capability catalog, decision trees, and reusable patterns.
- Provide golden paths, reference architectures, and bootstrap guides.
- Establish GitHub quality gates and environment promotion boundaries.
- Make the repository usable as a template.

## v0.9.x — Validation

- Exercise each golden path against representative Fabric projects.
- Add traceable examples without embedding tenant-specific data.
- Validate prompts and tests with maintainers and domain reviewers.
- Refine source freshness and compatibility metadata.

## v1.0.0 — Governed baseline

- Stabilize document contracts and navigation.
- Publish compatibility and release support policy.
- Establish a reviewed extension process for capabilities and bundles.
- Provide evidence that all approval boundaries work in practice.

## Beyond v1

Potential work includes machine-readable catalogs, richer project generators, and additional validation automation. These remain ideas until accepted through [Governance](GOVERNANCE.md).
