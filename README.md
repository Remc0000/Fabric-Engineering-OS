# Fabric Engineering OS

A GitHub-first operating system for governed AI-assisted engineering on Microsoft Fabric.

## Principles

- Microsoft Fabric is the primary platform.
- GitHub Copilot is the runtime.
- GitHub MCP is the repository interface.
- Microsoft Learn MCP is the authoritative documentation source.
- Humans remain accountable for merge and production approval.

## Vision

Fabric Engineering OS provides:

- Agent Bundles
- Capability Catalogs
- Golden Paths
- Reference Architectures
- Governance
- Repository Bootstrap

for building Microsoft Fabric solutions at scale.
